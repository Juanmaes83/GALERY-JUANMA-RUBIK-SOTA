# Fundación Arenas — collection asset rights

Every file in this directory is **our own work**.

They were produced by running this module's own plate generator
(`scene-kits/museum/textures.js`) at print resolution and exporting the result,
using a fixed seed so the collection is reproducible. The generation script is
kept at `qa/tools/make-assets.mjs`.

| Field | Value |
|---|---|
| Author | Escaparates Pro (generated by the Immersive Worlds module) |
| Rights | Owned. Free to use, modify and distribute within the product. |
| Third-party content | **None.** No photograph, painting, scan, dataset, model or texture from any external source is present. |
| Depicts | Nothing real. The Fundación Arenas, its five artists and its eleven works are invented. |
| Constitution | Satisfies §29.1 — `CONTENT = controlled / fictitious / owned`, and IW-DEC-006. |

## Why these exist at all

IW-1 generated every plate in the browser at runtime. That proved the fallback
path but never proved the one that matters commercially: **an institution
supplying its own files.**

These files exercise the real pipeline — `content.media` declared in the world
JSON, resolved by `render/media-loader.js`, hung by the Museum Scene Kit. Replace
them with a client's photographs and the same world definition shows the client's
collection.

## Replacing them

Point `content.media.src` at your own file and set `content.media.rights` to
describe who owns it. The validator refuses a world whose media declares no
rights, which is deliberate: an institution has to be able to answer that
question before its collection goes on a wall.
